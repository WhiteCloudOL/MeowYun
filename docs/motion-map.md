# 当前动效地图

用户最新修订优先：导航、标签、选项、正文和卡片主体保持水平；不再用旋转/歪斜作为交互。静态装饰背板保持固定角度。CSS 模拟弹性，不是物理引擎。

| 位置                     | 触发与层级                                     | 时序                      | 打断 / 触屏 / 静止                                                     |
| ------------------------ | ---------------------------------------------- | ------------------------- | ---------------------------------------------------------------------- |
| 首页欢迎、前六个列表条目 | 第一次进入视口；有限短位移，结束移除类         | 430ms，55ms 错峰          | 800ms 清理；内容立即可用；静止直接显示                                 |
| 原头像                   | 仅图像承托层 3px 微浮                          | 7s                        | 离屏/后台暂停；轻柔与静止不循环                                        |
| 云团向导                 | 眼睛短暂眨眼；点击真实回应                     | 8s 周期，绝大部分时间睁眼 | 开关可隐藏；离屏/后台暂停；静止保留表情                                |
| 主要按钮                 | 仅皮肤按压与释放，命中区域不动                 | 100ms / 430ms             | 快速再次操作重启；轻柔 180ms；静止只变颜色                             |
| 项目卡、漫游/工坊入口    | 皮肤形变，背板平移 2px，图标/箭头局部提示      | 430ms                     | 无永久终态；触屏按压；键盘焦点；轻柔去掉形变                           |
| 导航、标签、选项         | 背景/描边/文字状态                             | 160ms                     | 不旋转、不压缩文字；真实选中和焦点始终可见                             |
| 文章/项目到详情          | 同一文章封面或项目插画的共享快照               | 240ms，页面淡变 180ms     | 单一 viewTransitions.ts 协调；快速导航跳过旧动画；系统 reduce 直接导航 |
| 收藏 / 印章              | 爱心短回弹、一次印章通知                       | 430ms；通知最多 4s        | 数据先更新；重复印章不重复弹；写入失败另行提示                         |
| 随机发现                 | 新结果纸签滑入                                 | 400ms / 6px               | 点击立刻抽取，按钮不等待动画；空数据禁用                               |
| 明信片                   | 抓取指针、真实位置/缩放/透明度、边界夹紧、撤销 | 拖动实时                  | 只捕获画布；另有图层选择和位置按钮；无全局滚动锁                       |
| 日夜与氛围               | Token 同步改变背景、表面、文字和按钮           | 即时状态 + 短 CSS 过渡    | 尊重旧偏好，失败可在本次使用；不清空收藏                               |
| 搜索 / 设置 / 日历       | 短淡入与 4px 位移                              | 约 160ms                  | Escape，焦点恢复；模态使用 dialog；静止无位移动画                      |
| 全局点击微光             | 鼠标松开后一个光圈与三点                       | 430ms                     | 单次替换，拖动/选区不触发；轻柔仅光圈；关闭/静止立即清除               |
| 阅读返回顶部             | 边缘按钮，原生滚动                             | 原生平滑滚动              | 用户可打断；系统 reduce 立即滚动；正文不弹跳                           |

所有监听、观察器和组件计时器卸载时清理；全局偏好单例在 HMR 时释放。没有声音自动播放，也没有跟随鼠标的全屏拖尾。
