# 云间手账 · 全站优化实施记录

## 目标与边界

保留真实资料、头像、角色素材、文章 slug、10 条现有路由和纯静态部署。首页有个性，展示页轻盈，阅读页安静。用户已授权关键阶段 Conventional Commit 和 GitHub push；不部署、不接入后端。

基线：工作区干净，2026-09-15 重新获取 7 类页面的桌面与手机截图。旧审计 75 项按实测、代码风险、设计判断分别跟踪，不能全部称为已发生 Bug。

## 设计基准

- 颜色：暖白背景 `#FBF7F5`、纸面 `#FFFEFA`、墨色 `#443A45`、粉色 `#F2A0BB`、薄荷 `#BFDCCA`、蓝紫 `#DCCFED`；交互文字另用深色语义值保障对比。
- 深色：紫灰背景 `#1F1B25`、纸面 `#2B2533`、浅墨 `#F1EAF1`，共享组件不硬编码白底。
- 字体：品牌使用本机圆润 UI 字体及可靠系统回退；正文使用系统中文无衬线；日期与代码使用系统等宽。不下载中文字体，不假定未加载字体生效。
- 版面：自然滚动，欢迎文字与拍立得约 3:2；作品采用重点卡带 + 两个简卡；最新文章开放列表；档案与贡献适量收尾。
- 特色：保留卡带与拍立得，减少印章、装订环、重复装饰。普通内容细边轻影，正文稳定纸面。
- 唯一语义来源：`src/styles/tokens.css`；Tailwind 与旧兼容变量只映射，不另设配色。

```text
悬浮导航（共享避让）
欢迎文字  /  拍立得
重点卡带  /  两个精选项目
最新文章列表 → 完整归档
个人小记 + 技术方向 / 贡献记录
自然流页脚
```

## 阶段与页面映射

1. 基线与计划：读取项目和审计，重定位问题，保留前截图。
2. 基础与首页：Tokens、主题/安静偏好、背景、导航、页脚、基础控件、自然滚动首页。
3. 全站迁移：归档、详情、导航、友链、404、缺失文章、可信外链中转。
4. 交互与真实数据：共享快速查找、搜索历史/组合输入、手机目录、复制、贡献边界、可选近况与维护信息。
5. 验证与交付：类型/lint/回归/构建/生产预览、多断点/主题/失败态截图，75 项登记，自包含 HTML 与 ZIP，文档更新、提交、推送。
